# Diwali Sales Analysis

This project analyzes Diwali sales data using Python, Pandas, NumPy, Matplotlib, and Seaborn. The notebook focuses on cleaning the sales dataset and exploring sales patterns across gender, age groups, states, marital status, and occupation.

## Project Overview

The goal of this project is to perform exploratory data analysis (EDA) on Diwali sales data and identify patterns in orders and sales amounts.

The analysis includes:

* Data loading and inspection
* Handling missing values
* Removing unnecessary columns
* Converting data types
* Descriptive statistics
* Gender-wise sales analysis
* Age-group analysis
* State-wise order and sales analysis
* Marital-status analysis
* Occupation-wise sales analysis
* Data visualization using Seaborn and Matplotlib

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The notebook uses a CSV file named:

`DiwaliSalesData.csv`

The dataset contains information related to customers, orders, sales amount, gender, age group, state, marital status, and occupation.

## Data Cleaning

The dataset is first inspected using methods such as `shape()`, `head()`, `info()`, and null-value checks.

The following cleaning steps are performed:

* Removed the `Status` and `unnamed1` columns.
* Removed rows containing missing values.
* Converted the `Amount` column from its original type to integer.
* Examined the structure and descriptive statistics of the dataset.

## Exploratory Data Analysis

### Gender Analysis

The project analyzes the number of customers/orders by gender and calculates the total sales amount for each gender.

Bar charts are used to visualize the differences in sales between genders.

### Age Group Analysis

The notebook examines the distribution of customers across different age groups and compares the total sales amount generated by each age group.

### State-wise Analysis

The project analyzes the top states based on:

* Number of orders
* Total sales amount

The top 10 states are visualized using bar charts.

### Marital Status Analysis

The notebook examines the distribution of customers based on marital status and further compares sales by marital status and gender.

### Occupation Analysis

The project analyzes the number of customers across different occupations and calculates the total sales amount generated by each occupation.

## Visualizations

The notebook uses:

* Count plots
* Bar plots
* Grouped bar plots

These visualizations are created primarily with Seaborn and Matplotlib to make the sales patterns easier to understand.

## How to Run

1. Clone or download the repository.
2. Make sure Python is installed.
3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

4. Place `DiwaliSalesData.csv` in the same directory as the notebook.
5. Open `code.ipynb` using Jupyter Notebook or JupyterLab.
6. Run the cells sequentially.
